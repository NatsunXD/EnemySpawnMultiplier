EnemySpawnMultiplier v24 by Natsun

Install
-------
Close the game, remove the previous ESM package, then deploy exactly one package
with HDArsenal or HD2MM. Requires the official Bingus Shared Loader v15+:
https://github.com/CowboyBingus/BingusSharedLoader/releases

Press F8 for settings. Optional Mod Options Menu v1.1+ with loader v18+ provides
the same settings in MODS. Both interfaces apply, synchronize and save settings
to %LOCALAPPDATA%/EnemySpawnMultiplier.cfg. Chinese and English are supported.

Default build: Dynamic spawn compensation
----------------------------------------
The switch defaults ON and controls all of the following:
- All 65 mission progression multipliers are locked to exactly 1.00.
- Extraction bonuses above 1 are halved: 1.20 becomes 1.10.
- Patrol extraction-distance refresh-rate multipliers are limited to 1.00-1.20.
- Three consecutive valid 1-second samples with H=Q+B >100 reduce patrol count
  and size to 1+(user-1)*0.10. User values at or below 1 stay unchanged.
  Count and size immediately recover linearly over 20 seconds.
- Patrol rate becomes user*0.75, holds for 6 seconds, then recovers over 4 seconds.
  A new trigger restarts both the 20-second quantity and 10-second rate timers.

Switch OFF cancels the response and restores native progression/extraction
curves. Background changes never move sliders or enter the saved profile.
Saved ON/OFF preferences remain respected on upgrade.

S70 and H100 diagnostics continue with the switch OFF. S70 does not control
parameters. H omits candidate squad size and does not count actual rejections.

Other build profiles
--------------------
Explicit panel/panel-menus/panel-local/panel-performance builds retain the older
progression-only experiment: initial-tier compensation without pressure sampling.
The local-soft-limit-test build retains its isolated legacy test: always-on
initial-tier compensation, with a separate optional H100 response (three H>95
samples or one H>100 sample; count/size 1x, half rate for 10 seconds).
These profiles differ from the default combined-compensation package above.

Runtime scope and diagnostics
-----------------------------
Compensation is enabled only on the supported Steam 25480438 / 1.8.46015.0
hashes. The mod changes validated private data, without executable-code patches
or native spawn calls. Native population gates remain active. Public matchmaking
and a used host SOS beacon gate spawn writes.

Log: %LOCALAPPDATA%/EnemySpawnMultiplier.log
The panel can export diagnostics to the Desktop.
Addon: mods/natsun/enemy_spawn_multiplier
Offline tests do not establish in-game stability of the exact package.

Uninstall
---------
Close the game, disable the mod, purge deployment, then redeploy remaining mods.
