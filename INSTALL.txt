Enemy Spawn Multiplier 6x - maintained variants

Close the game before upgrading. Replace previous Enemy Spawn Multiplier
entries with exactly one package: Enemy-Spawn-Multiplier-6x-Native-Composition-v13.zip
for native composition, or Enemy-Spawn-Multiplier-6x-Light-Medium-Bias-v13.zip
for lower-cost-per-unit template bias.
Keep Bingus-Shared-Loader-v12.zip enabled, then deploy both using HDArsenal
or HD2MM. Use one manager. Restart the game to discard previous memory edits.
The existing mod resource identity and GUID are unchanged. Choose one package
only: both are v13; Native Composition keeps the native template mix, while
Light-Medium Bias favors light and medium
groups while retaining the same spawn multipliers.

This build scales the Encounter base composition budget by 6 and nonzero
per-type caps by 5. It resolves the active config through the director hash table
or native resource-key fallback. A read-only resource table is cloned to
private writable memory and retargeted before editing. It then shortens Patrol/Straggler intervals to
one fifth (minimum 0.2s), and multiplies their group clamp by 5.
Example: Straggler 20-40s -> 4-8s, Patrol 8-14s -> 1.6-2.8s,
group clamp 10 -> 50. The group clamp is an upper limit, not a fixed count.

This build never changes executable memory and does not import executable-page
protection or instruction-cache APIs. It uses the native budget override field
at cfg+0x78, scales the encounter target to 2x with a cap of 95, and leaves
the native 70, 448, desired-reached and combined-100 population exits at their
vanilla behavior. Only writable private data
is changed. Native timestamps, ProducedFighter counters,
pending queue quantities and director+0x36C0 remain read-only.
Actual spawn totals still depend on demand, population limits, templates
and spawn-location queries; offline tests do not establish a 5x live count.

For each active Encounter candidate pool, the biased v13 ranks template cost
divided by planned unit count. The lower half receives 3.6x selection weight,
the next 30% receives 1.25x, and the highest-cost 20% receives 0.25x. This is a relative
three-faction policy, not a hard-coded enemy type list.

The base release is data-v13-native and the biased release is
data-v13-light-medium, both displayed as v13 and built for
Steam build 24826606 / EXE 1.8.45317.0.
Loader-v2 / API 1 or later with this mod resource registered is required.

After a mission starts, check %LOCALAPPDATA%/EnemySpawnMultiplier.log:
data-v13-native or data-v13-light-medium + spawn_multiplier_ready means the
active data config and native
budget override were scaled.
spawn_multiplier_partial means only budget/caps applied; cfg= gives the
config failure reason and checks continue. i=, g= and d= should be nonzero
for a valid active config. cfg=director:... or cfg=resource:... shows its
source/address. d= is the scaled desired target; l=vanilla confirms the
native population exits were not patched. w= is biased/available candidate
weights. t=0 is expected; x= is the native
ProducedFighter count.

For a comparison, use the same mission type/difficulty and host role.
Check Patrol and Encounter behavior separately. Record the three log lines,
elapsed time, approximate units per event and any prolonged spawn pauses.

To uninstall: close the game, disable this mod, purge deployment, and
redeploy the remaining mods.
