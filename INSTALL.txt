Enemy Spawn Multiplier

Close the game before installing or upgrading. Remove previous Enemy Spawn
Multiplier entries, then install exactly one package. All packages share one
resource ID and cannot be combined.

What the packages do
--------------------

- Native Composition keeps the game's native Encounter composition weights and
  raises overall spawn pressure.
- Light-Medium Bias raises overall spawn pressure and steers Encounter
  composition toward lighter and medium units.
- Fast Cadence shifts the emphasis from wave size to cadence and composition.
  Enemy reinforcement arrives on a much shorter cooldown. Both the wave
  composition and its point budget are steered toward heavier units, so a wave
  is made of fewer but heavier units rather than being larger overall. Patrols
  appear more frequently, in greater numbers, and in larger groups.

The mod changes writable private data only. A game update does not by itself
disable it: the build hash is reported to the log but no longer blocks the
patch, and every write is validated against the live layout before it lands.
It does not modify executable code and does not call native spawn functions.
Native population gates, position checks, template availability and queue
processing all remain active.

Install
-------

1. Close the game.
2. Install and enable the official Bingus Shared Loader v15 or newer
   (https://github.com/CowboyBingus/BingusSharedLoader/releases) and give it the
   winning startup priority.
3. Import exactly one of the packages published on the releases page into
   HDArsenal or HD2MM.
4. Deploy, then start the game.

Diagnostics are appended to %LOCALAPPDATA%/EnemySpawnMultiplier.log.

Uninstall
---------

Close the game, disable the mod, purge deployment, then redeploy the remaining
mods.
